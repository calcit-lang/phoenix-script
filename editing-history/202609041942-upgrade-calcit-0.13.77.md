# Upgrade phoenix-script to Calcit 0.13.77 / 将 phoenix-script 升级到 Calcit 0.13.77

## English

- Migrated the compact legacy source into the canonical `calcit.cirru`
  Snapshot and selected the JavaScript entry explicitly.
- Pinned Calcit and `@calcit/procs` to 0.13.77, added `js-ffi` 0.1.12, Yarn 4,
  esbuild 0.28.2, Node 24 CI, deterministic dependency installation, and a
  production bundle; removed the retired `compact.cirru` after migration and
  made the Phoenix watch output follow the actual `$HOME` path.
- Replaced nullable raw Phoenix calls with runtime object guards plus typed
  external-object traits for logging, shortcut registration, recent windows,
  focus, and maximize effects.
- Added an architecture scaffold, concrete function schemas, a reviewed
  `unsafeCoerce` quality baseline, and positive and negative Node host-contract
  tests.
- Aligned `Window.recent` with its required non-null object contract and pinned
  every CI action to a verified immutable commit with least-privilege checkout.

The legacy 0.13.48 runtime could not parse the compact namespace form, so the
pre-upgrade evidence is that migration-time parser failure rather than a
successful old-runtime execution. The migrated 0.13.77 Snapshot is verified by
check-only preprocessing, JavaScript code generation, static quality checks,
the Node smoke test, and esbuild bundling.

## 中文

- 将旧版 compact 源码迁移为规范的 `calcit.cirru` Snapshot，并明确选择
  JavaScript entry。
- 将 Calcit 与 `@calcit/procs` 固定到 0.13.77，加入 `js-ffi` 0.1.12、Yarn 4、
  esbuild 0.28.2、Node 24 CI、确定性依赖安装与生产 bundle；迁移完成后删除
  已退役的 `compact.cirru`，并让 Phoenix watch 输出使用实际的 `$HOME` 路径。
- 用运行时对象校验和 typed external-object traits 替换可空的 Phoenix 原始调用，
  覆盖日志、快捷键注册、最近窗口、聚焦与最大化能力。
- 增加架构 scaffold、具体函数 schema、经审阅的 `unsafeCoerce` 质量基线，
  以及 Node 正向和反向宿主契约测试。
- 将 `Window.recent` 收紧为必需的非空对象契约，并把所有 CI Action 固定到已验证的
  不可变 commit，同时使用最小权限 checkout。

旧版 0.13.48 runtime 无法解析 compact namespace 形式，因此升级前证据是迁移期
解析失败，而不是伪造的旧 runtime 成功结果。迁移后的 0.13.77 Snapshot 会通过
check-only 预处理、JavaScript codegen、静态质量检查、Node smoke test 与 esbuild
bundle 验证。
